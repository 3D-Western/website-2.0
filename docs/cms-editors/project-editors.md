# CMS Editor Guide

This guide is for content creators and editors managing projects in the Payload CMS.

## Accessing the Admin Panel

1. Navigate to `http://localhost:3000/admin`
2. Log in with your admin credentials
3. Click on **Projects** in the left sidebar

## Creating a New Project

1. Click the **Create New** button in the top right
2. Fill in the required fields:
   - **Title** — Project name
   - **Slug** — URL-friendly identifier for the project's page
   - **Creator** — Name of the project's creator
   - **Contributors** — Names of everyone who worked on it, including the creator
   - **Description** — What the project is, what it does, who it's for
   - **Image**
     - **Src** — Direct link to the image
     - **Alt** — Description for accessibility
   - **Categories** — Select up to 3 categories that describe the project (pulled from the **Project Categories** collection)
3. Optional fields:
   - **Gallery Images** — Additional images shown alongside the project (each with its own Src and Alt)
   - **GitHub** — Link to the project's repository
   - **Blog URL** — Link to a related blog post, if one exists
   - **Featured** — See below
4. Click **Save** to save as a draft

## Featuring a Project

1. Open the project
2. Toggle **Featured** on
3. Click **Save**

**Note:** Featured projects are meant to highlight a small number of standout projects — use it selectively rather than on everything.

## Saving & Publishing

### Save as Draft

- Click the **Save** button
- Status shows as "Draft" — only visible via a preview link or to authenticated users
- Changes autosave a few seconds after you stop typing, so you won't lose in-progress edits

### Publish

1. Click the **Save** button
2. At the top, change Status from **Draft** → **Published**
3. Click **Save** again
4. Project is now live

## Preview Before Publishing

1. Save your project as a draft
2. Click the **Preview** button (top right area)
3. A new tab opens showing the project as it will appear live
4. Share the preview URL with others for feedback

**Note:** Preview links require authentication.

## Editing Published Projects

1. Find the project in the **Projects** collection
2. Make your changes
3. Click **Save** — changes are live immediately

## Categories

Categories help visitors browse and filter projects by type. You can select up to 3 per project.

**To add categories to a project:**

1. In the Categories field, click **Add**
2. Search and select from existing categories
3. Save the project

**Creating new categories:**

- Contact an admin to add new categories in the **Project Categories** collection

## Deleting a Project

Only admins can delete projects. If a project needs to come down, contact an admin rather than trying to delete it yourself — as an editor, you can still unpublish it (set Status back to Draft) in the meantime.

## Common Issues

### "Required field missing"

- Check: Title, Slug, Creator, Description, at least one Category, Image (Src and Alt)
- All of these must be filled in

### "Too many categories"

- Projects can have a maximum of 3 categories — remove one before adding another

### Project not appearing on the site

- Verify status is **Published** (not Draft)
- Clear browser cache and refresh

### Preview link not working

- Make sure you're logged in
- Preview links are user-specific
- Refresh the page and try again

### Can't delete a project

- Deletion is admin-only — ask an admin, or unpublish it yourself in the meantime

## Best Practices

✅ **Do:**

- Write a description that explains the project to someone unfamiliar with it
- Add at least one relevant category
- Fill in image alt text for accessibility
- List all real contributors, not just the lead creator
- Only mark a small number of projects as Featured

❌ **Don't:**

- Add more than 3 categories
- Feature everything — it defeats the purpose of a "featured" section
- Publish with blank required fields

## Getting Help

If you need help:

1. Check this guide first
2. Ask another editor
3. Contact the dev team (link to Slack/email)
